# 安全設定與已知風險

- 固定官方 Syncthing 2.1.7，驗證 archive 與 EXE 的 SHA-256；未修改其 TLS、裝置驗證或傳輸協定。一般使用公共探索／中繼／NAT；本機測試關閉這些服務。
- 朋友必須透過可信的既有通訊管道核對雙方完整裝置 ID，兩端各自授權。名稱不是身分，連線圖示不是對方已人工確認的證明。沒有短代碼授權、中央朋友清單或線上帳號。
- 未知裝置不自動加入，未知資料夾不自動接受。每個資料夾只有一位指定朋友。解除朋友時先撤所有資料夾權限，再刪裝置設定。已傳給朋友的內容無法從遠端收回。
- REST/GUI 僅綁定 IPv4 回環，API key 每次啟動產生，無寫死金鑰、無應用程式診斷檔案內容日誌。Syncthing 原生設定仍需明文 API key、私鑰，不能用 DPAPI 直接加密後交給未修改引擎；使用獨立 ACL 目錄保護（目前使用者與 SYSTEM）。請搭配 Windows 帳戶保護及磁碟加密。管理員、SYSTEM 或同帳戶惡意程式仍可取得它們。
- 傳送／保存拒絕重新解析點、符號連結、接合點、絕對／越界路徑、ADS、Windows 保留裝置名稱及尾端空白／句點。雲端佔位檔也可能被拒絕；請先下載至一般本機資料夾。Syncthing Windows 不跟隨同步中的符號連結；固定資料夾啟用前另外檢查全樹及父目錄。不防範具有同帳戶權限的惡意程式競爭改寫本機資料夾、硬連結或工作紀錄。
- 一次收件採專用且不可預測的目錄，根目錄只接受 Files、清單與引擎標記；每個清單路徑驗證、逐檔長度與 SHA-256 驗證，拒絕重複與未列內容。清單由朋友提供，驗證代表與其提供的內容一致，不代表內容安全或可信；朋友本身仍可能傳惡意檔案。
- 不自動執行、預覽或解壓收到的檔案，只能開啟所在資料夾。獨立保存的每個檔案加上 Windows Internet Zone ADS。正式保存需本機 NTFS。未完成接收或保存驗證失敗時不會冒稱成功。
- 保存時短暫停整個引擎以避免驗證／搬移時遠端競爭寫入。完成後正式檔案不再共享；資料夾在同磁碟重新命名，跨磁碟則保留原副本並重驗。不要將正式收件位置另行設成 Syncthing 或其他軟體的共享目錄。
- 固定資料夾是單向鏡像，仍傳播刪除。接收端版本保留只涵蓋部分遠端修改，備份需另外建立。單次傳送可手動清理本機暫存。清理前須明確取消共享並確認永久刪除，程式會比對工作路徑和引擎設定，且只在指定工作目錄內刪除檔案。清理一旦開始，該暫存便不能再共享。
- 收件磁碟採 Syncthing 原生 2 GB 最低剩餘空間門檻。新收件、升級後的既有收件共享與跨磁碟保存皆適用。這是磁碟保留門檻，沒有每人或每次收件配額。並行寫入及其他程式仍可能用掉磁碟空間。拒絕邀請會在本機記住當次邀請，取消共享或解除配對可停止後續傳入。
- 公共探索服務可取得裝置 ID、外部位址與查詢／宣告時間；本地探索廣播區網裝置資訊。中繼可觀察雙方連線位址、時間與流量，無法解密經驗證的端到端傳輸內容。直連優先，防火牆／NAT 環境可能使用中繼或無法連線。沒有廣告、追蹤碼、帳號或本產品檔案內容蒐集。
- 沒有網路自動更新功能，引擎自身自動升級也停用。使用經驗證且由開發者簽署的新完整安裝檔更新。此預覽版尚未 Authenticode 簽章，SHA-256 可驗證固定來源／完整性，但不能取代發佈者簽章或防止整個安裝包被置換。不要關閉 SmartScreen、防火牆或防毒來使用。
- Windows Defender Firewall 的程式路徑授權可能需要系統政策／管理員；軟體不擅自新增防火牆規則。中繼是低操作負擔的替代，但不能保證每個網路都可連線。
- 收件安全不等於資料永遠不會外洩。沒有對所有網路、惡意朋友、被入侵主機、磁碟故障或人為誤刪的絕對保證。
